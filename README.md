# Lok Sevak Gateway

Build a modern, responsive, AI-powered government services web application called LOK SEVAK.

PROJECT PURPOSE

LOK SEVAK solves the problem:

“System integration and interoperability among government digital platforms, resulting in fragmented service delivery.”

The platform should provide a single unified interface where citizens can discover government services, identify the correct department, reuse citizen information, automatically fill forms, and interact with multiple simulated government department systems through an interoperability layer.

This is a Smart India Hackathon prototype, so the website should be visually impressive, realistic, easy to understand, and designed for a judge to explore within 2–3 minutes.

---

MOST IMPORTANT REQUIREMENT: NO LOGIN REQUIRED

Do NOT require login, signup, OTP, account creation, or personal information before using the prototype.

The website must be fully accessible in Demo Mode / Guest Mode.

On the landing page, prominently display:

🚀 Start Demo

When the user clicks Start Demo, automatically load a pre-configured demo citizen profile and allow the user to explore all major features immediately.

The judge should never have to:

- Create an account
- Login
- Enter OTP
- Fill personal information
- Upload real documents

Everything should work using realistic sample/demo data.
